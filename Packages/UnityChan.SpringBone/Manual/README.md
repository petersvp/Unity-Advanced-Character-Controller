# Unity-Chan SpringBone manual

The English manual is organized into three chapters:

1. [Components and setup](SpringBoneManualComponents.md) — SpringManager, SpringBone, colliders, pivots, forces, and a setup walkthrough.
2. [Editor windows](SpringBoneManualWindow.md) — the SpringBone tools, mirroring, selection, and parenting windows.
3. [Loading and saving](SpringBoneManualLoadAndSave.md) — dynamics CSV import, export, and file format.

Start with **Components and setup** if you are adding SpringBone to a character for the first time. The original Japanese text is preserved in [ja](ja/).
